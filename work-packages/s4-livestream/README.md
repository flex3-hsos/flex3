# S4 – Livestream

Überträgt eine Vorlesung live an Studierende, die nicht im Hörsaal sind. Hintergrund: `knowledge-base/architecture/live-pipeline.md`.

## Ziel

Der Steuerrechner schickt einen Stream an den FLEX³-Server, der ihn an die Studierenden verteilt. Als früher, schneller Erfolg ist eine Weiterleitung an YouTube möglich; für Untertitel ab S5 liefern wir selbst aus.

## Fertig, wenn

Ein Stream aus dem Live-Simulator (OBS) ist für Studierende im Browser abrufbar.

## Stand

Geplant für P1 (Januar bis März 2027).
