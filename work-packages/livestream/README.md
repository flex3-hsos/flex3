# 6 · Livestream

Überträgt eine Vorlesung live an Studierende, die nicht im Hörsaal sind (Ausbaustufe S4). Hintergrund: `knowledge-base/architecture/live-pipeline.md`.

## Ziel

**In zwei Schritten.**

1. **Direkt zu YouTube:** Der Mischer streamt ohne Umweg zu YouTube. Kein Code, sofort nutzbar, reicht für S4. Als weiterer Weg ist das Gerät als Kamera in einer Teams- oder Zoom-Sitzung im Gespräch; welche Plattform Lehrende wollen, klärt eine Befragung.
2. **Eigene Auslieferung** über den FLEX³-Server per LL-HLS. Gebraucht erst, wenn Untertitel für Studierende zu Hause mit dem Bild synchron laufen sollen (Teil 7c im Paket `live-subtitles`).

## Fertig, wenn

- Schritt 1: Eine Vorlesung läuft live auf YouTube, und die Anleitung dafür passt auf eine Seite.
- Schritt 2: Ein Stream aus dem Live-Simulator (OBS) ist für Studierende im Browser abrufbar.

## Stand

Schritt 1 geplant für P1 (Januar bis März 2027); Schritt 2 braucht eine zusätzliche Person.
