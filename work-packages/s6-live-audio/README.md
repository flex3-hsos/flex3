# S6 – Echtzeit-Audiospur

Erweitert S5 um eine übersetzte Sprachausgabe, die Studierende statt oder zusätzlich zu den Untertiteln hören können. Hintergrund: `knowledge-base/architecture/live-pipeline.md`.

## Ziel

Dieselbe Pipeline wie S5 plus Sprachausgabe (TTS) in der Zielsprache, ausgespielt als zusätzliche Audiospur.

## Fertig, wenn

Mit dem Live-Simulator ist eine übersetzte Audiospur im Browser wählbar und hörbar.

## Stand

Geplant für P3 (August bis September 2027).
