# Arbeitspakete

Jedes Arbeitspaket hat einen eigenen Ordner. Ihr arbeitet nur im Ordner eures Arbeitspakets; welches das ist, steht im Projektboard und nach `/onboarding` in `local/profile.md`.

| Ordner | Stufe | Inhalt | Phase |
|---|---|---|---|
| [device-simulator/](device-simulator/) | – | erzeugt Sitzungsordner ohne Hardware; Testgrundlage für alles Weitere | P0 |
| [device/](device/) | Track H | Konfiguration und Skripte des Steuerrechners im Gerät | P0–P2 |
| [s1-recording-upload/](s1-recording-upload/) | S1 | Ingest-Endpunkt und Upload nach Opencast/ILIAS | P0 |
| [s2-transcription/](s2-transcription/) | S2 | Transkriptionskomponente, WebVTT, Sprungmarken | P0 |
| [s3-ai-content/](s3-ai-content/) | S3 | Zusammenfassung, einfache Sprache, Quiz, Prompt-Bibliothek | P0 |
| [s4-livestream/](s4-livestream/) | S4 | Livestream | P1 |
| [s5-live-subtitles/](s5-live-subtitles/) | S5 | Echtzeit-Untertitel | P2 |
| [s6-live-audio/](s6-live-audio/) | S6 | übersetzte Audiospur in Echtzeit | P3 |
| [s7-dubbing/](s7-dubbing/) | S7 | nachträgliches Dubbing | P4 |

Wie ein Arbeitspaket aufgebaut ist, steht in `knowledge-base/standards/conventions.md`. Das README jedes Arbeitspakets ist seine Dokumentation und wird mit jeder Lösung aktualisiert.
